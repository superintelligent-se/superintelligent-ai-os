# Bidra till Superintelligent AI OS

Tack för att du vill bidra. Det här repot växer med erfarenheter från AI-experter i praktiken.

## Vad vi välkomnar

- Nya workflows för återkommande AI-arbetsuppgifter
- Nya templates för vanliga outputformat
- Connector-guider för verktyg vi inte täcker än
- Förbättringar av befintliga skills och beteenden
- Buggfixar i skript

## Vad vi inte tar emot

- Privat data, kunddata eller personuppgifter
- API-nycklar, tokens eller credentials
- Verktygsspecifika interna guider som inte är generellt applicerbara

## Hur du bidrar

1. Forka repot
2. Skapa en branch: `git checkout -b feature/mitt-bidrag`
3. Gör dina ändringar
4. Kör säkerhetskontrollen: `bash scripts/safety-check.sh`
5. Committa: `git commit -m "Add: beskrivning av vad du lagt till"`
6. Pusha och öppna en Pull Request

## Stil och ton

Följ brandprincipen i `CLAUDE.md`:
- Tydlig, modig, mänsklig, praktisk och premium
- Inga AI-klichéer eller hype
- Beskriv AI som mänsklig förmåga
