# Workflow: Folder to Report

Används för att omvandla en mapp med filer och anteckningar till en strukturerad rapport.

## Syfte

Aggregera material från en projektmapp, kundmapp eller arkiv till ett läsbart och presentabelt dokument.

## Input

- En mapp med filer (anteckningar, mejl-utdrag, data, bilder)
- Rapportens syfte och mottagare
- Önskad längd och format

## Steg

### 1. Inventera materialet
- Lista alla filer i mappen
- Kategorisera: bakgrund, data, beslut, övrigt
- Identifiera vad som är relevant för rapporten

### 2. Definiera rapportstrukturen
```
1. Sammanfattning (executive summary)
2. Bakgrund och syfte
3. Fynd / resultat
4. Analys
5. Rekommendationer
6. Nästa steg
```

### 3. Skriv ett utkast
- Börja med sammanfattningen — skriv den sist men placera den först
- Håll varje avsnitt fokuserat på en idé
- Använd `templates/client-report.md` som grund

### 4. Granska och rensa
- Ta bort allt som inte bidrar till rapporten
- Kontrollera att privat data inte ingår innan du delar

### 5. Leverans
- PDF för extern leverans
- Markdown eller Word för intern användning
