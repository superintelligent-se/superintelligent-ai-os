# Mac Mini Migration Guide
**Datum:** 2026-06-09  
**Från:** MacBook (laptop) → Mac Mini (headless 24/7-server)

---

## Översikt

| Komponent | Laptop (behålls) | Mac Mini (nytt hem) |
|---|---|---|
| Cowork-sessioner, dagligt arbete | ✅ | – |
| Schemalagda tasks | ❌ inaktiveras | ✅ körs härifrån |
| `hourly-inbox-triage` | inaktiveras | aktiveras |
| `nightly-github-sync` | inaktiveras | aktiveras |
| MS365-plugin | behålls | installeras |
| Repo `superintelligent-ai-os` | behålls | klonas |

---

## Steg 1 — Förbered på laptopen (kör före migrering)

### 1a. Exportera credentials (kör skriptet)

```bash
# Kör från repo-roten på laptopen:
bash scripts/migrate/export_credentials.sh
```

Skriptet skapar en krypterad fil `credentials_export.enc` på skrivbordet.  
Lösenordet du väljer behöver du på Mac Mini — välj ett du minns.

### 1b. Kontrollera att token är fräsch

```bash
cd ~/Github/Superintelligent/superintelligent-ai-os
python3 scripts/outlook/reauth.py
```

Om det lyckas utan fel är refresh_token giltig. Om det misslyckas: kör om autentiseringen via `scripts/outlook/auth_setup.md` innan du migrerar.

### 1c. Notera dina scheduled task-inställningar (referens)

| Task | Cron | Aktiverad |
|---|---|---|
| `hourly-inbox-triage` | `0 7-22 * * *` | ja |
| `nightly-github-sync` | `0 2 * * *` | ja |

## Steg 2 — Sätt upp Mac Mini

### 2a. Installera grundverktyg

Öppna Terminal på Mac Mini och kör:

```bash
# Installera Homebrew om det saknas
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Python 3 + Git
brew install python git

# Verifiera
python3 --version   # kräver 3.9+
git --version
```

### 2b. Sätt upp GitHub-åtkomst

```bash
# Generera SSH-nyckel (om ingen finns)
ssh-keygen -t ed25519 -C "thomas@superintelligent.se"
cat ~/.ssh/id_ed25519.pub
```

Lägg till pubnyckeln i GitHub: **Settings → SSH and GPG keys → New SSH key**

Verifiera:
```bash
ssh -T git@github.com
# Förväntat: "Hi thomasdalebring! You've successfully authenticated..."
```

### 2c. Kör setup-skriptet

Kopiera `setup_mac_mini.sh` till Mac Mini (t.ex. via AirDrop eller `scp`) och kör:

```bash
bash ~/setup_mac_mini.sh
```

Skriptet gör:
- Skapar `~/Github/Superintelligent/`
- Klonar repot från GitHub
- Sätter upp Python virtual environment
- Installerar alla dependencies
- Verifierar att scripts fungerar

### 2d. Återställ credentials

Kopiera `credentials_export.enc` till Mac Mini, sedan:

```bash
cd ~/Github/Superintelligent/superintelligent-ai-os
mkdir -p .secret
openssl enc -d -aes-256-cbc -pbkdf2 -in ~/Desktop/credentials_export.enc \
  -out .secret/credentials.json
chmod 600 .secret/credentials.json
```

Verifiera att token fungerar:
```bash
python3 scripts/outlook/reauth.py
```

## Steg 3 — Installera och konfigurera Claude på Mac Mini

### 3a. Installera Claude

Ladda ner Claude desktop-appen från **claude.ai/download** och logga in med samma Anthropic-konto.  
Minnet och konversationshistoriken följer automatiskt med kontot.

### 3b. Installera Productivity-pluginet

I Claude: **Settings → Plugins** → sök "Productivity" → installera.

### 3c. Koppla MS365-pluginet

I Claude: **Settings → Plugins → Productivity → Configure** → logga in med `thomas@superintelligent.se`.  
Detta är den enda plugin Mac Mini behöver för att köra de schemalagda tasks.

### 3d. Välj repot som workspace

I Claude Cowork: klicka **Select Folder** → välj `~/Github/Superintelligent/superintelligent-ai-os`.

## Steg 4 — Skapa schemalagda tasks på Mac Mini

Skapa båda tasks i Claude på Mac Mini. Kopiera SKILL.md-innehållen exakt från:

| Task | SKILL.md-källa |
|---|---|
| `hourly-inbox-triage` | `Claude Entrepreneur OS/Scheduled/hourly-inbox-triage/SKILL.md` (OneDrive) |
| `nightly-github-sync` | `Claude Entrepreneur OS/Scheduled/nightly-github-sync/SKILL.md` (OneDrive) |

> **OBS:** SKILL.md-filerna för hourly-inbox-triage har uppdaterats (se nedan) för att använda dynamisk sökväg. Använd den uppdaterade versionen — inte den gamla med `/sessions/eloquent-admiring-goldberg/`.

### Inställningar per task

**hourly-inbox-triage:**
- Cron: `0 7-22 * * *`
- Task ID: `hourly-inbox-triage`

**nightly-github-sync:**
- Cron: `0 2 * * *`
- Task ID: `nightly-github-sync`

## Felsökning

| Problem | Orsak | Lösning |
|---|---|---|
| `FEL: .secret/credentials.json saknas` | Credentials ej kopierade | Kör steg 2d igen |
| `Token expired` | Access token gammal | Kör `python3 scripts/outlook/reauth.py` |
| `git push` misslyckas | SSH-nyckel ej upplagd | Kontrollera GitHub SSH-inställningar |
| Telegram-notis uteblir | Bot-token felaktig | Verifiera `telegram.bot_token` i `credentials.json` |
| Task körs dubbelt | Aktiv på båda maskiner | Inaktivera på laptopen (steg 5) |
