# Connector: Fantastical

Ger AI-agenten åtkomst till kalender och kalenderhantering via Fantastical MCP-servern.

## Förutsättningar

- Fantastical installerat på macOS
- Claude Code eller Claude Cowork med MCP-stöd
- Fantastical MCP-servern aktiverad

## Vad du kan göra

- Visa kommande möten och händelser
- Söka i kalender på datum, titel eller person
- Skapa nya kalenderhändelser
- Modifiera befintliga händelser
- Hitta lediga tider för mötesbokningar

## Exempel på kommandon till agenten

```
Vad har jag för möten imorgon?
```
```
Hitta en ledig tid på 1 timme nästa vecka för ett kundmöte
```
```
Skapa ett möte "Projektstatus" nästa måndag kl 10:00
```

## Säkerhet

- Kalenderdata är privat — committas aldrig i detta repo
- Agenten ska fråga dig innan den skapar eller ändrar händelser
- Delade kalendrar kan innehålla andras privata uppgifter — hantera varsamt
