# Connector: Canva

Ger AI-agenten möjlighet att skapa och redigera designs i Canva via Canva MCP-servern.

## Förutsättningar

- Canva-konto (Pro rekommenderas för full funktionalitet)
- Claude Code eller Claude Cowork med Canva MCP konfigurerat

## Vad du kan göra

- Söka bland befintliga designs
- Skapa nya designs från templates
- Redigera befintliga designs
- Exportera färdiga designs
- Arbeta med brand kit-element

## Kom igång

1. Öppna Claude Code
2. Säg: "Anslut Canva" eller "Skapa en LinkedIn-bild i Canva"
3. Agenten guidar dig genom auktoriseringsflödet

## Arbetsflöde för brand content

1. Börja med `templates/canva-brief.md`
2. Fyll i brief
3. Be agenten: "Skapa en design i Canva baserat på den här briefen"
4. Granska och justera direkt i Canva-editorn

## Viktigt

- Agenten kan inte se eller läsa ditt befintliga bildbibliotek utan att du pekar på specifika designs
- Exporterade filer sparas lokalt — inte i detta repo
